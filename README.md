# markdown-render-speed-02

A faster drop-in for marked 18.1.3: `parse.js` renders exactly the HTML
marked renders (CommonMark 0.31.2 + GFM 0.29), for less CPU time.
`main.ts` renders every case from `/input/cases.json` and writes
`/output/html.json`.

Built by an AI agent for make.fun's "Make Markdown rendering faster" bounty.
